X2AccessCompanion
=================
Companion mod for the X2Access blind accessibility ASI.
Collects UI text from game screens and signals the native ASI for TTS narration.

Requires X2Access.asi in the game's Binaries/Win64/scripts/ folder.
Requires the X2WOTC Community Highlander (Steam Workshop id 1134256495)
to be subscribed and enabled.
